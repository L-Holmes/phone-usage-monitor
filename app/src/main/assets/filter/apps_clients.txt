# THIRD-PARTY CLIENTS FOR BLOCKED SERVICES  -  blocked outright.
#
# ⚠️ WHY THIS FILE EXISTS  (2026-08-27)
# Every other app list here blocks a SERVICE by blocking the app the service ships. That
# stops working the moment somebody installs a different app that signs in to the same
# account and shows the same feed. Blocking com.reddit.frontpage while "Infinity for
# Reddit" is one search away is not blocking Reddit; it is blocking one icon.
#
# So this list is the same services again, reached through somebody else's app. The
# reported example was FlickFolio, a third-party Flickr client - Flickr's own app is on
# apps_ugc.txt, and FlickFolio walked straight past it.
#
# THIS LIST CAN NEVER BE COMPLETE, and it is not meant to be. It is the seed. The detector
# (ClientMarkers / ProxyClients) is what catches the ones nobody has heard of - it watches
# for a service's own sign-in page or its own vocabulary inside an app that is not that
# service's app. This file is here so the well-known ones are blocked from the first run,
# before the detector has ever seen them.
#
# Format:  Friendly Name = package.name        ("#" = comment.)
# LANGUAGE-NEUTRAL. Loaded by FilterData -> BlockedCategories.
#
# ⚠️ Only package names I could state with confidence are listed. A wrong entry that
#    happens to be a real other app blocks an innocent app, so do not guess - let the
#    detector find it instead, which at least records WHY.
